## 📖 เกี่ยวกับเกม (About The Game)

ยินดีต้อนรับสู่ชีวิตจริงยิ่งกว่านิยายของ **"ช่างไอทีประจำออฟฟิศ"**! เมื่อคอมพิวเตอร์ทั่วทั้งตึกเริ่มพัง จอฟ้าพรึ่บ พรินเตอร์ระเบิด ไวรัสแพร่ระบาด และที่แย่ไปกว่านั้น... มี **Hacker ลึกลับ** แอบบุกเข้ามาป่วนระบบถึงในบริษัท!

ภารกิจของคุณคือรับบทเป็นยอดมนุษย์ IT Support วิ่งซ่อมคอมพิวเตอร์ให้ทันเวลา รับมือกับเคสฉุกเฉิน และใช้ไม้ตะบองไอทีไล่หวดสกัดแฮกเกอร์ก่อนที่เน็ตเวิร์กของบริษัทจะล่มสลาย!

## ✨ ไฮไลท์และระบบเด่น (Key Features)

- 🏢 **3D Office Environment:** สำรวจออฟฟิศ 3 มิติเต็มรูปแบบ พัฒนาด้วยเทคโนโลยี Three.js ให้ความรู้สึกลื่นไหลบนเบราว์เซอร์
- ⏱️ **Time Attack Challenge:** การแข่งขันกับเวลาสุดระทึก วิ่งเคลียร์ Ticket ซ่อมอุปกรณ์ไอทีก่อนความอดทนของพนักงานจะหมด
- 🦹 **Hacker Intrusion & Combat:** สกัดกั้นแฮกเกอร์ที่แฝงตัวเข้ามาในออฟฟิศ ใช้ไม้ทุบสกัดก่อนที่มันจะปล่อยมัลแวร์ทำลายเซิร์ฟเวอร์
- ⌨️ **Mini-games & Terminal Hacking:** มินิเกมแก้โค้ด ถอดรหัส กำจัดไวรัส และดีบักระบบเน็ตเวิร์ก
- 🏆 **Score & Combo System:** ยิ่งแก้ปัญหาได้เร็วและต่อเนื่อง ยิ่งทำแต้มคอมโบไต่สู่อันดับท็อปของตาราง IT Support ดีเด่น
- 🤖 **Created with Google AI Studio:** พัฒนาและขับเคลื่อนโค้ดด้วย Google AI Studio

## 🎮 วิธีการเล่นและการควบคุม (Controls & How to Play)

| ปุ่มกด (Key) | การกระทำ (Action) |
| :---: | :--- |
| <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> หรือ <kbd>↑</kbd> <kbd>←</kbd> <kbd>↓</kbd> <kbd>→</kbd> | เคลื่อนที่ตัวละครช่างไอทีไปรอบๆ ออฟฟิศ |
| <kbd>E</kbd> หรือ <kbd>คลิกซ้าย</kbd> | โต้ตอบ (Interact) ซ่อมเครื่องคอมพิวเตอร์ / ตรวจสอบอุปกรณ์ |
| <kbd>F</kbd> หรือ <kbd>Spacebar</kbd> | ใช้ไม้ตะบองไอทีหวดสกัดกั้นแฮกเกอร์ (Whack Hacker) |
| <kbd>V</kbd> หรือ <kbd>C</kbd> | สลับมุมมองกล้อง: **TPP (บุคคลที่ 3 ใกล้ชิด)** / Overview (มุมสูง) / FPP (บุคคลที่ 1) |
| <kbd>F2</kbd> หรือ <kbd>~</kbd> | เปิด Dev Studio จัดการโมเดลตัวละคร FBX และท่าทาง |
| <kbd>Esc</kbd> | หยุดเกมชั่วคราว (Pause Game) / เปิดหน้าตั้งค่า |

## 🛠️ เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

- **Frontend Core:** [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **3D Graphics:** [Three.js](https://threejs.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Build Tool:** [Vite](https://vitejs.dev/)
- **Icons & UI:** [Lucide React](https://lucide.dev/)
- **Audio & FX:** Web Audio API & Canvas Confetti
- **Developed With:** 🤖 [Google AI Studio](https://aistudio.google.com/)

## 🚀 การติดตั้งและรันโปรเจกต์ (Local Development)

หากต้องการนำไปรันบนเครื่องของคุณเอง:

1. **Clone repository นี้ลงเครื่อง:**
   ```bash
   git clone https://github.com/Game-The-IT-Support/Game-The-IT-Support.github.io.git
   cd Game-The-IT-Support.github.io
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **รัน Development Server:**
   ```bash
   npm run dev
   ```

4. **เปิดเบราว์เซอร์แล้วไปที่:**
   ```text
   http://localhost:3000
   ```

5. **Build สำหรับนำขึ้น GitHub Pages:**
   ```bash
   npm run build
   ```
